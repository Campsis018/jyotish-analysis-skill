# 输入与设置指纹

## 来源顺序

用户指定的原始成盘和明确口径 > 同设置可复现的计算输出 > 旧报告转录 > 对话中的概括。现实发生事实独立记录，不能与占星推论相互代证。成盘与出生资料冲突时保留双方，定位冲突，不静默选一个。

## 最低数据及降级

| 输入 | 能做什么 | 不能补造什么 |
| --- | --- | --- |
| 精确D1坐标与设置 | 本命结构、宫主、标准数学校核 | 未提供的力量表和专题分盘 |
| D1＋D9/专题分盘 | 主题兑现与跨盘质量 | 未提供的年度盘与行运 |
| MD/AD/PD打印日界 | 阶段激活 | 缺本命时的具体事件 |
| 出生时间范围 | 敏感性比较 | 未经计算的“差一分钟必换盘” |
| 只有日期/泛述 | 已知范围内的学习讨论 | 上升、精确分盘与具体日期预测 |

缺出生资料但完整成盘可读时，不强制重新收集个人身份。只问影响当前结论的缺项，问题集中一次提出，并继续独立部分。

## 设置指纹字段

- 出生：日期、时间、时区、DST、经纬度、资料来源、时间误差范围；不把地方平太阳时与法定时混淆。
- 坐标：恒星/回归黄道；岁差名称、版本/实现；地心/站心；视/真位置。
- 交点：真/平均；Rahu与Ketu是否相差180°。
- 宫位：整宫或具体Bhava算法；保留Rasi星座与Bhava宫位两个字段。
- 相位：Parashari Graha Drishti；节点默认不加5/9；若用Jaimini Rashi Drishti另列规则。
- 分盘：逐个写算法变体，特别D2、D3、D10、D16、D20、D24、D30及高阶分盘。
- 指标：默认八星制、Rahu逆向度数、排除Ketu、软件并列/跳号/替代分配规则。原盘已有角色时原样保留。
- 大运：Janma Moon起点、年长、起算点、边界时区、输出取整；不以软件默认推断用户已采用。
- 年度：出生地TP为主；具体回归定义、软件实现、太阳月约束另记；Tajaka独立注明地点。
- 软件：名称、版本、原文件页码、重算日期、历表/算法来源。

## 数学校核

星座用1=白羊至12=双鱼；绝对黄经在[0,360)。整宫宫位 `((星座−上升星座) mod 12)+1`。跨宫制时不能把此公式当Bhava校核。

27宿每宿13°20′、每Pada3°20′；边界归入下一段。需保留原始精度，显示四舍五入不得改变分段。标准Parashari D9可用 `floor((绝对黄经×9) mod 360 / 30)+1`；若输入仅到整分且接近边界，应标注原精度不足。

D9由D1相同黄经确定，因此D1尊贵度与D9状态是相关视角，不能伪称独立实验。生日时间范围内的分盘稳定性需实际重算，再说明哪些结论受影响。

## 软件不一致

依次检查：同一个人及同一次资料 → 时区/DST → 坐标顺序正负号 → 黄道/岁差 → 交点 → 宫制 → 分盘变体 → 年长/起点 → 显示取整。不要先把差异说成流派错误，也不要拿一份第三方样例的设置替用户定口径。
