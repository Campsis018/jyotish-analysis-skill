# D1骨架与行星状态

## 行星底表

每星记录：原始度数｜星座与宫位｜所主宫位｜星宿/Pada｜逆行｜尊贵度｜合相与相位｜星座定位星｜个人指标角色｜力量与来源｜D9/专题分盘。

传统星座主：白羊/天蝎火星，金牛/天秤金星，双子/处女水星，巨蟹月亮，狮子太阳，射手/双鱼木星，摩羯/水瓶土星。默认不把外行星或交点替换为星座主。

从上升及上升主、日月、角宫/三角宫、集中宫轴、2/6/8/11/12资源与成本链建立骨架。空宫依然有宫主；群星不能按数量自动判强。

## 强弱不是一个数

| 维度 | 所回答问题 | 禁止替代 |
| --- | --- | --- |
| 功能宫主与结构 | 管什么、有没有通道 | 自然吉星＝对所有上升都吉 |
| 尊贵度 | 星座内表达条件 | 本垣/擢升＝无成本 |
| Shadbala | 多维发力与相对所需力量 | 140%＝140%好运 |
| Ishta/Kashta | 该计算口径内的顺阻倾向 | 人生幸福分或成功概率 |
| Bhava Bala | 宫位承载的相对力量 | 宫分低＝人生事件不存在 |
| Vimsopaka/Vaiseshikamsa | 多分盘尊贵与质量概况 | 一个总值取代D10或D9具体结构 |
| Avastha/Activity | 所选状态体系中的表达状态 | Mrita等字面翻成死亡、废星 |

Shadbala通常有Virupa、Rupa与相对需求百分比。1 Rupa=60 Virupa；百分比的分母随行星而异，不是“占全盘总力量的百分比”。采用原软件阈值并注明；节点在别的强度表有值，不等于拥有经典七曜Shadbala。

Ishta−Kashta可作辅助差值，但标明是整理指标，不称“古典净吉凶总分”。平方根法 `I=√(U×C)`、`K=√((60−U)×(60−C))` 与Rashmi/其他成果法分栏。变量和太阳/月亮处理随实现而异；不得混列两套数，也不从这个公式推出二者必定和为60。

Avastha有多种同名或不同分类体系；先登记具体系统再解释。只看到一个状态标签不足以压倒宫主与落点。

## 角色与成本合并

按“结构资格 → 发力能力 → 顺阻 → 兑现领域”写一句完整判断，例如：某星有明确教育/资源通道，力量略低但跨盘支持尚可；当前瓶颈是执行与持续投入。这个判断不能简化为一颗弱星或一颗大吉星。

逆行、燃烧、星战、落陷取消各自登记。逆行不自动擢升，燃烧不抹去全部功能，Neecha-bhanga不自动等同Raja Yoga。星战先查参与资格、黄经差和所用胜负判据；缺纬度等所需数据时只记候选，不假判赢家。

## 处置链

先按传统星座主生成有向图。追到本垣自环、互容/多星环或各自终点。节点默认交给所在星座主并结合合相；不以星宿主替换星座主。星宿处置链可另开一层，不把两种边混成一个图。

最终定位星能解释多个主题共享的通道，但不能免除逐专题审查。一个终点状态费力会影响多个链条；这仍是同源证据，不能重复计票。
