# Yoga、相位与矛盾结构

## 判定流水线

先写采用的具体定义/版本，再核对形成几何、宫主、承载星、尊贵度、力量、苦乐果、状态、分盘、受克和运期。软件列出的Yoga名称只视为候选。不要复述经典夸张赞词为现实保证。

| 状态 | 定义 |
| --- | --- |
| 成立 | 所选定义的必要条件已核实 |
| 成立且受修正 | 形成条件具备，承载/成本有具体限制 |
| 候选 | 存在核心关联，仍缺必要信息或定义未选定 |
| 不成立 | 至少一个必要条件明确不满足 |

不要把Yoga成立状态与预测窗口A/B/C/D混成同一种等级。

## 常用审查卡

- Pancha Mahapurusha：核验火/水/木/金/土在角宫且本垣或擢升的所选定义；明确参考上升。形成后继续读受克与分盘，不能同宫多颗星就判组合无效。
- Dharma-Karmadhipati：核验9主、10主及所选定义要求的Sambandha。9主与10主没有关系时，不能只因事业强就冠名。
- Raja/Dhana：列出具体角/三角或财富宫主关系、双重宫主混合效应与结果通道。不把命主星强单独说成所有Raja Yoga成立。
- Saraswati：先固定水金木的宫位许可与木星尊贵条件版本，再逐星校核，不能只因三吉星较好就命名。
- Viparita：审6/8/12主的落点、与其他宫主纠缠和版本纯度；上升主兼困难宫主时保留自我成本。
- Neecha-bhanga：列具体取消条件及参考点、条件星强度；取消、恢复、形成Neecha-bhanga Raja Yoga分开。
- Vesi/Vasi/Ubhayachari及月亮两侧组合：先核对所选版本排除哪些星，不能直接把交点计入形成条件。
- Amala、Vasumati等：是否要求纯吉星、从上升或月亮、是否排除混合受克，必须说明版本，不能看到10宫金星就自动承诺声誉纯正。

本文件提供核查框架，不冒称包含所有Yoga的统一定本。冷门定义须读取一手出处或标注未核实。

## 相位口径

七曜均有第7全相；火星另4/8、木星5/9、土星3/10。计算以所在宫/星座为第1，不能把“第7”误加7个星座。节点默认只读同宫、对轴和定位星，不加5/9特殊相位。

本命相位先按所选Parashari规则成立；度数接近度用于内部强调，不把西占容许度当一刀切门槛。若要连续Drik Bala，使用对应度数模型并注明，不能拿整宫相位个数代替数值算法。

Jaimini Rashi Drishti单独列：活动照固定但排除相邻固定，固定照活动但排除相邻活动，双体互照。不能把它与Graha Drishti叠成“同一颗星有更多特殊相位”。分盘相位的采用与流派规则另记。

## 矛盾矩阵

每项写“承诺—支持—具体限制—兑现方式”。例如强事业结构与高责任成本可以同时成立；不能用成本抹掉成就，也不能用成就推定快乐。无反证时直接确认支持，不为表格完整凭空生成限制。
